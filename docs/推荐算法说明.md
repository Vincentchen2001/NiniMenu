# NiniMenu 推荐算法说明（人话版）

> 更新日期：2026-06-11（对应 v0.7.1）。本文不含任何代码，所有数字与线上逻辑一致；
> 文中「规则页」指 设置 → 高级推荐规则。

## 0. 一句话总览

系统像一位家庭点菜师傅：先把**没资格上桌的菜筛掉**，再按你定的**每日框架**（主题 + 几荤几素几汤）给每道候选菜**打分**，每个位置选分数最高的那道；实在凑不齐就**逐步放宽要求**，并在页面上提示你。

应用里有三个推荐入口，复杂度从高到低：

| 入口 | 干什么 | 用哪套逻辑 |
|---|---|---|
| 一周菜单 | 一次排好 7 天午晚餐 | 完整流程（过滤 → 框架 → 打分 → 规则 → 放宽） |
| 明日推荐 | 按主题推几道明天的菜 | 同样的过滤和打分，但没有荤素汤框架和规则引擎 |
| 今晚吃什么（转盘） | 随机抽一道 | 只过滤不打分，纯随机（收藏的菜中签率 ×3） |

---

## 1. 第一关：谁有资格被推荐（候选池）

| 筛选条件 | 说明 |
|---|---|
| 菜品必须「启用」 | 菜品详情里关掉开关的菜，任何入口都不会出现 |
| 避开家庭忌口 | 菜名、食材、调料命中忌口词（设置里的「忌口/过敏」）直接排除 |
| 分餐别 | 标了「仅午餐」的菜不会出现在晚餐，反之亦然；「不限」两边都可以 |
| 最近吃过的进冷却期 | 最近 N 天（默认 3 天，可在设置改）吃过、或已经排进计划的菜，暂时不推荐 |
| 一周菜单内不重复 | 周一排过的菜，周二到周日不再排（同一周内全局去重） |

> 冷却和去重是「尽量做到」：如果菜太少凑不齐，会放宽（见第 5 节）。

---

## 2. 第二关：每天的点菜框架

一周菜单按「工作日 / 周末」两套偏好生成，每套各自设定：

| 设定项 | 含义 |
|---|---|
| 口味主题 | 均衡 / 快手 / 清淡 / 想吃辣 / 收藏 / 靓汤，决定当天打分倾向 |
| 每餐配额 | 午餐和晚餐各要 几荤、几素、几汤 |
| 单日覆盖 | 任何一天可以单独改主题、加「这天想吃」的食材偏好 |
| 想吃偏好 | 周级「本周想多吃」+ 天级「这天想吃」（猪/牛/羊/鸡鸭/鱼虾/蛋/豆制品） |

生成时，每一餐按配额拆成若干「位置」（荤位 / 素位 / 汤位），**逐个位置挑分数最高的菜**。菜是荤是素是汤，由系统从菜名和食材自动识别（详情页可手动改）。

---

## 3. 第三关：打分

每道候选菜的得分 = **加分项 − 减分项**，另加 0～1 的随机微调（让同分的菜不至于每次都同一个顺序）。

### 3.1 加分表

| 加分项 | 分值 | 什么时候给 |
|---|---|---|
| 位置对口 | +60 | 荤菜站荤位、素菜站素位、汤站汤位 |
| 匹配当日主题 | +40 | 菜符合当天主题（均衡主题下人人都拿，等于不加） |
| 这天想吃 | +25 | 菜的主料命中「这天想吃」的食材 |
| 收藏 | +12 | 你收藏过这道菜 |
| 本周想多吃 | +12 | 主料命中「本周想多吃」 |
| 主题细分加分 | +4 ~ +30 | 见下表 |
| 特征手动校对过 | +4 | 你在详情页人工确认过菜的属性，数据更可信 |

主题细分加分（在 +40 匹配分之外的小倾斜）：

| 主题 | 额外加分 |
|---|---|
| 快手 | 难度简单 +18；越快分越高（35 减去烹饪分钟数，例：8 分钟的菜再 +27） |
| 清淡 | 口味带「清淡」+18、带「鲜」+10；清汤 +8 |
| 想吃辣 | 口味带辣 +18；川菜/湘菜/贵州菜 +8 |
| 收藏 | 收藏的菜再 +30（也就是收藏日里收藏菜共领先约 82 分） |
| 靓汤 | 汤 +18；炖煮类做法 +8 |
| 均衡 | 难度简单 +6；35 分钟内 +4（轻微偏向省事的菜） |

### 3.2 减分表（即规则页里的「打分类」预设规则，分值都可调、可关）

| 规则 | 什么时候扣 | 扣多少 |
|---|---|---|
| **未收藏的菜降分** ★新 | 这道菜你没收藏（收藏 = 会做） | -12 |
| **陌生菜系降分** ★新 | 这道菜所在菜系一道收藏都没有（视为基本不会做） | -25 |
| **工作日少排费时汤** ★新 | 周一到周五的汤位，遇到炖煮超 45 分钟或难度高的汤 | -30 |
| 同餐主蛋白不重样 | 一餐里已有同种主蛋白的菜（豆制品除外） | -14 |
| 辣菜同餐不扎堆 | 一餐里已有辣菜，又来一道辣菜 | -12 |
| 费时菜同餐最多一道 | 一餐里已有超 45 分钟的菜，又来一道 | -15 |
| 重油重辣一天最多一道 | 当天已有重油重辣的菜 | -18 |
| 一周蛋白换着吃 | 同种主蛋白一周吃到第 4 次起 | -20 |
| 油炸一周最多两次 | 一周已排 2 道油炸，又来油炸 | -20 |

★ 三条新规则的含义：**收藏 = 会做**。新疆菜你一道没收藏 → 每道新疆菜都背着 -37（-12-25）起跑，正常竞争基本上不了桌，只在菜不够时偶尔冒头——这是故意留的「学新菜」口子；云南菜你收藏了一两道 → 那一两道零扣分正常推荐，同菜系其他菜只背 -12。

### 3.3 一票否决表（「约束类」规则，不是扣分而是直接出局）

| 规则 | 效果 |
|---|---|
| 同餐蛋类最多一道 | 番茄炒蛋 + 蛋花汤 不会同餐出现 |
| 同餐凉菜最多一道 | 凉菜不会一餐两道 |
| 同餐主食最多一道 | 米线、炒饭、饼类一餐只来一道 |

### 3.4 数字的段位感（帮你建立直觉）

位置对口（+60）> 主题匹配（+40）> 不会做的菜系惩罚（-37）> 这天想吃（+25）> 收藏（+12）。
也就是说：**惩罚拼不过「位置 + 主题」的硬需求，但足以在势均力敌的菜之间分出胜负**——这正是「软降权、不赶尽杀绝」的设计意图。

## 4. 汤的特殊逻辑（v0.7.1 修正）

| 问题 | 以前 | 现在 |
|---|---|---|
| 什么汤算「清淡」 | 只要分类带「汤」就算，猪肚鸡汤也混进清淡日 | 必须同时满足：汤品类、口味不带「浓」、油腻度低 |
| 费时汤什么时候出现 | 不分日子随机出 | 工作日 -30 分（优先紫菜蛋花汤这类快手汤），周六日不扣（炖汤回归周末） |

---

## 5. 凑不齐怎么办：六级放宽阶梯

每个位置先用全部条件挑，挑不出就一级一级放宽，每放宽一级页面会显示一条提示：

| 级别 | 放弃什么 | 人话 |
|---|---|---|
| 1 | 不放弃 | 全条件严格挑选 |
| 2 | 最近避重 | 「前几天刚吃过」也可以再排 |
| 3 | 口味画像 | 不再要求匹配当天主题 |
| 4 | 全周唯一 | 本周排过的菜可以再排一次 |
| 5 | 可降级规则 | 所有「打分类」规则失效（包括三条新降权） |
| 6 | 菜品角色 | 荤位可以放素菜等，只求把位置填上 |

> 设计取舍：**宁可推荐不太合适的菜，也不让菜单开天窗**。如果你常看到放宽提示，说明菜品库该补菜了（或收藏太少）。

## 6. 三个入口的差异

| | 一周菜单 | 明日推荐 | 今晚吃什么 |
|---|---|---|---|
| 候选过滤（启用/忌口/冷却） | ✅ | ✅ | ✅ |
| 荤素汤配额 | ✅ | ❌（按主题出整批） | ❌ |
| 打分排序 | ✅ 全套 | ✅ 主题打分 + 三条新降权 | ❌ 纯随机（收藏中签率 ×3） |
| 规则页的规则 | ✅ 全部生效，分值可调 | ⚠️ 只镜像三条新降权的**默认分值**（规则页改分/关闭不影响这里） | ❌ |
| 周末判定 | 按菜单上那天是周几 | 按「明天」是周几 | 无 |

## 7. 你能调什么（控制面板对照）

| 想达到的效果 | 去哪操作 |
|---|---|
| 让会做的菜被优先推荐 | 给菜点收藏（核心数据源，收藏越全效果越准） |
| 彻底不推荐某道菜 | 菜品详情 → 关闭启用开关 |
| 整个菜系都不要 | 管理页按分类筛选 → 批量禁用 |
| 调整三条新规则的力度 | 规则页 → 对应卡片的「降多少分」步进器（作用于一周菜单） |
| 嫌惩罚太狠/太松 | 同上；觉得规则本身不对可以直接关掉 |
| 改冷却天数 | 设置 → 重复天数（默认 3 天） |
| 忌口 | 设置 → 忌口管理 |
| 每天吃什么风格 | 一周菜单页顶部主题条（按天设置） |

## 8. 实战例子

**例 1：周二晚餐的汤位（均衡主题，假设你没收藏任何汤）**

| 候选 | 加减分（只列有差异的项） | 相对得分 |
|---|---|---|
| 紫菜蛋花汤（8 分钟，简单） | 简单 +6、快 +4、未收藏 -12、菜系零收藏 -25 | **-27** ← 胜出 |
| 莲藕排骨汤（90 分钟） | 未收藏 -12、菜系零收藏 -25、工作日费时汤 -30 | -67 |
| 猪肚鸡汤（120 分钟，难） | 同上 | -67 |

→ 工作日汤位稳定出快手汤。到了周六，-30 消失，炖汤就能正常竞争了。

**例 2：周四晚餐的荤位（均衡主题，你收藏了红烧肉，没收藏任何新疆菜）**

| 候选 | 加减分 | 相对得分 |
|---|---|---|
| 红烧肉（家常菜，已收藏） | 收藏 +12 | **+12** ← 胜出 |
| 大盘鸡（新疆菜，未收藏） | 未收藏 -12、菜系零收藏 -25 | -37 |

→ 差距 49 分，大盘鸡正常情况上不了桌；但如果某天主题是「想吃辣」而红烧肉不辣、大盘鸡带辣（+18 +40 匹配），差距就可能反转——这就是留给「学新菜」的口子。

## 9. 底层语义备忘

- **收藏 = 会做**：这是整个会做感知功能的约定，没有新增任何字段；收藏数据越完整，推荐越贴合现实。
- 菜的辣度、油腻度、荤素角色、蛋白来源、烹饪方式都由系统从菜名/食材/做法**自动识别**，识别不准可以在菜品详情里手动改（手动校对过的菜打分时 +4）。
- 三条新规则随 v0.7.1 自动加入；迁移**不会**动你改过或关掉的旧规则。
